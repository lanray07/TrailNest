# TrailNest visual system

The generated concept is `dashboard-concept.png`. The built-in image generator created it and `website/assets/landscape.png`; both project assets are retained locally. The landscape is an imaginary illustration, never a route photograph or map. The original vector trail/hill icon remains in the separate website preview at `website/assets/logo.svg`. Android 0.8.1 and the Amazon draft listing use the new premium medallion; its master, prompt and export details are in [PREMIUM-ICON.md](PREMIUM-ICON.md).

Tokens: forest `#285C4D`, ivory `#F7F5EE`, teal `#287E83`, earth `#8D7159`, ink `#26332E`, sage `#E8ECDF`. Editorial serif headings, sans-serif control text, restrained borders, 12–20 px panel corners and 44–48 px primary touch targets. Dark surfaces use forest-tinted charcoal with light text. Android uses Compose theme tokens; website uses CSS custom properties.

Concept brief: full TrailNest dashboard; five navigation destinations; editorial nature illustration; empty reviewed-route collection; country search; route-type filters; checklist and journal shortcuts. No fictional recommendations, metrics or mapped tracks. Standalone asset prompt: layered green hills, lake, winding path and ivory negative space, no labels or real location.

Original website implementation differences: simplified vector icon for small-size rendering; a separately generated landscape asset rather than extracting concept pixels; no decorative signpost/contour illustration; safer copy about preparation and geometry-only offline packs. These preserve the product hierarchy while avoiding unsupported marketing claims. This is a reviewed adaptation, not a claim of pixel-identical implementation.
