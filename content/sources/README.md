The public OpenStreetMap relation response in this directory is © OpenStreetMap contributors, available under the [Open Database Licence 1.0](https://opendatacommons.org/licenses/odbl/1-0/). [Attribution and database rights](https://www.openstreetmap.org/copyright).

`osm-9351283.json` preserves the source relation, way identifiers, tags and geometry used to create the unpublished Tamsin Trail draft. The source response includes its database timestamp. The original database and the derived geometry in `content/routes.json` are offered under ODbL-1.0, including the applicable share-alike obligations. TrailNest's original editorial notes are separate from that source geometry. The downloadable source files in this public repository are the corresponding database source.

This source is not evidence of current public access, safety, accessibility, a human review or a published walking itinerary. Do not ship draft records. Re-imports must retain the previous source hash and trigger another review when geometry or access changes.
